小语种检查 · 使用说明
======================

用途：把图片 / 文件拖进网页，自动识别里面的文字；只要出现中、英、日、韩以外的文字
（法语、德语、俄语、泰语、阿拉伯语、越南语……），就标为“小语种”，并可一键整理到
“小语种”文件夹，附上备注（识别到的语种和原文）。

全部在本机运行，不上传任何文件，不需要联网。


一、运行要求
------------
· macOS 13 (Ventura) 或更高版本
· Apple 芯片（M1/M2/M3/M4…）的 Mac：解压即用，什么都不用装
· Intel 芯片的 Mac：第一次启动会自动下载依赖（需联网，约 1~3 分钟）


二、第一次打开（只需做一次）
----------------------------
1. 解压后，把“小语种检查”文件夹放到任意位置（如“文稿”或“桌面”），不要在压缩包里直接运行。
2. 双击“启动小语种检查.command”。
3. 如果弹出“无法打开 / 无法验证开发者 / Apple 无法检查是否包含恶意软件”：
   方法 A：点“完成”关闭提示 → 打开“系统设置 → 隐私与安全性”，拉到最下面，
           点“仍要打开” → 再次双击启动文件，输入开机密码确认。
   方法 B：打开“终端”App，输入  bash （后面有一个空格），把“启动小语种检查.command”
           拖进终端窗口，按回车。
4. 之后都可以直接双击启动。


三、日常使用
------------
1. 双击“启动小语种检查.command”，会弹出一个终端窗口并自动打开浏览器页面。
   ※ 使用期间不要关闭终端窗口；用完关掉它即可退出。
2. 等页面右上角显示“引擎就绪”。
3. 把图片、文件夹、zip、PDF、Word(docx)、txt 拖进页面上方的虚线框
   （也可以点“选择文件 / 选择文件夹”，或在框里输入本机路径后点“扫描路径”）。
4. 自动开始识别，每张卡片会标出：
      小语种（红）/ 疑似小语种（橙）/ 非小语种 / 无法读取（灰，已自动跳过）
   点缩略图可看大图：红框 = 确定的外语文字，橙框 = 疑似。
   觉得判断不对，可点卡片下方“标为小语种 / 标为非小语种”手动修正。
5. 全部完成后建议点“未命中的用极致重扫”，用最大倍数再放大查一遍，找极小的字。
6. 在页面底部点“导出”，默认输出到桌面“小语种检查结果_日期时间”：
      小语种/                  确定的小语种文件（文件名带【法语】这类前缀）
      小语种/疑似待复核/       疑似的，建议人工再看一眼
      小语种/标注预览/         红框标出外语文字的预览图
      小语种/备注.csv          每个文件的语种、原文、备注（可用 Excel/Numbers 打开）
      无法读取的文件.txt       被跳过的文件及原因
      检查报告.csv             全部文件的检查结果
   备注同时写进了文件的“访达注释”，在访达里选中文件按 ⌘I 可以看到。


四、先试一试
------------
“示例图片”文件夹里有 8 个示例，直接把整个文件夹拖进页面即可：
   01~05 应判为小语种（法语、德语、俄语、乌克兰语、右下角极小的西班牙语）
   06、07 应判为非小语种（中英日韩、纯英文）
   08 是越南语 txt，演示文本文件也能检查


五、常见问题
------------
· 页面打不开 / 显示“服务未连接”：确认终端窗口还开着；关掉后重新双击启动。
· 识别慢：把“放大级别”调成“标准”；或调高“并发”（电脑越新可以越高）。
· 误报多 / 漏报多：把“灵敏度”调成“严格”或“宽松”。
· 纯英文单词（如 RESTAURANT、BOULEVARD）法语也在用，工具会按英文处理，不算小语种。
· 文字识别用的是 macOS 自带引擎，不认识希腊文、印地文、希伯来文等少数文字：
  这类图片通常仍会被标为“疑似”，但语种名称可能不准（如希腊文显示成俄语）。
· 仍有问题：把终端窗口和网页截图发给提供者。
